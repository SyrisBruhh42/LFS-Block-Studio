## 2. Required file contract

Use the [Sponge v3 specification pinned at 8e6be2d980d3bd794bc29df5fdca5921129fac5d](https://github.com/SpongePowered/Schematic-Specification/blob/8e6be2d980d3bd794bc29df5fdca5921129fac5d/versions/schematic-3.md), reconciled with the selected importer:

- Unnamed root NBT compound containing a **`Schematic` compound**; case-sensitive names. Gzip the NBT bytes. JSON renamed `.schem` is not this format.
- `Version`: NBT Int **3**; `DataVersion`: NBT Int **3955**. `Width`, `Height`, `Length`: unsigned 16-bit values carried by NBT Shorts. This profile requires positive dimensions, each ≤65,535, and checked dense volume ≤100,000 cells before allocation; the lower volume limit is an LFS work budget.
- `Offset`: NBT IntArray of exactly three signed integers. `Blocks.Palette`: compound mapping complete blockstate strings to nonnegative palette IDs. `Blocks.Data`: NBT ByteArray of varints with exactly one decoded ID per cell, indexed `x + z*Width + y*Width*Length`; validate membership, truncation and trailing data.
- Block entities, when supported, use local integer `Pos[3]`, namespaced `Id` and optional compound `Data`. Entities use local double positions. Biomes have their own palette/data container. These optional format capabilities do not imply first-profile support.

Emit a typed empty `Blocks.BlockEntities` compound-list for the initial subset; omit unsupported entity/biome containers. WorldEdit's [writer](https://github.com/EngineHub/WorldEdit/blob/7d32b456e7c3237a70e19cca129e51b790c33b73/worldedit-core/src/main/java/com/sk89q/worldedit/extent/clipboard/io/sponge/SpongeSchematicV3Writer.java#L180) emits that list and writes cells in Y/Z/X loop order. Its [Fabric adapter](https://github.com/EngineHub/WorldEdit/blob/7d32b456e7c3237a70e19cca129e51b790c33b73/worldedit-fabric/src/main/java/com/sk89q/worldedit/fabric/FabricPlatform.java#L86) obtains DataVersion from the running game: a fresh native save must independently confirm **3955**.

## 3. Implemented coordinate candidate and unqualified native policies

**Implemented local candidate contract:** `javaCellMapping.ts` and `JAVA_CELL_MAPPING_CONTRACT.md` retain integer cell addresses and translate render points by (+0.5, 0, +0.5), with strict exact-unit admission and local contract tests. Native registry/placement/readback remains NOT_RUN. The coordinate contract uses integer game-cell indices, +X east, +Y up, +Z south, consistent with the importer's [direction definitions](https://github.com/EngineHub/WorldEdit/blob/7d32b456e7c3237a70e19cca129e51b790c33b73/worldedit-core/src/main/java/com/sk89q/worldedit/util/Direction.java#L36). The source-backed adapter is now present; legacy content outside its exact admission remains unsupported. Do not round ambiguous half-cell placements into compliance.

For selected minimum cell **M**, authored paste anchor **A**, local cell **R=C−M**, and native paste point **P**, encode **Offset=M−A**. Expected paste is **P+Offset+R**. Omit `Metadata.WorldEdit.Origin` initially, leaving the reader's origin at zero. The selected [reader](https://github.com/EngineHub/WorldEdit/blob/7d32b456e7c3237a70e19cca129e51b790c33b73/worldedit-core/src/main/java/com/sk89q/worldedit/extent/clipboard/io/sponge/SpongeSchematicV3Reader.java#L95) computes clipboard minimum as `Offset + Origin`; the writer computes offset as minimum minus origin. Test this contract with negative coordinates and an anchor outside the selection. Do not promise that any paste point fits the target world's height/border.

**Initial policy proposal:** whitelist a small set of static full cubes plus explicit air; candidate first fixtures can use `minecraft:air`, `minecraft:stone`, `minecraft:cobblestone`, and `minecraft:oak_planks`. Confirm the actual IDs/states against the pinned/native registry before promising qualified compatibility. Experimental local candidate constraints/UI are not native acceptance. Store namespaced IDs and canonical complete properties, with deterministic property ordering and registry-checked values/defaults. Unknown IDs/properties, missing mappings and unsupported transforms reject the entire edit/export; never silently substitute air or a visually similar block.

Keep block entities, entities, biomes, fluids, gravity/support-dependent blocks, multiblock structures, connection-dependent states and modded blocks outside this initial subset. Add directional/stateful blocks only with state-aware rotation/mirror and post-update fixtures. Freeform scale, arbitrary meshes and micro-voxels remain Freeform content unless an explicit conversion is reviewed. A format example is not a valid 1.21.1 registry entry.

## 4. Smallest reproducible native test lane

**Proposed, NOT_RUN:** a separate local game directory using the owner's licensed Java launcher, the exact game/loader/mod above, Java 21, and a disposable Creative fixture world with commands enabled. No public server, CUI, graphics mods, extra data/resource packs or launcher replacement is needed. EngineHub's [installation guidance](https://worldedit.enginehub.org/en/latest/install/#fabric-single-player-or-server) describes this lane. A separate Fabric API install is unnecessary for this WorldEdit release: its [build script](https://github.com/EngineHub/WorldEdit/blob/7d32b456e7c3237a70e19cca129e51b790c33b73/worldedit-fabric/build.gradle.kts#L44) bundles the needed API modules.

Before execution, freeze a manifest with game/loader/mod versions, source refs, downloaded hashes, Java vendor/build, OS, WorldEdit banner/configuration, registry hash, world seed/settings, fixture hashes, and export revision. Resolve the actual schematic directory from configuration; Fabric normally uses `config/worldedit/schematics` under the instance directory. [Configuration reference](https://worldedit.enginehub.org/en/latest/config/).

Qualification sequence:

1. Independently decode each exported file and verify tag types, dimensions, palette, air, cell order, origin/offset and exact decoded length. Include asymmetric X/Y/Z markers, negative minima, nonzero anchors, internal air holes and boundary rejection fixtures.
2. In the pinned native instance, load `//schem load fixture sponge.3`, then paste at a recorded placement point using `//paste -s`. Keep air enabled; record masks, side-effect configuration and all flags. Test `-a` separately because it intentionally changes air behavior. No `-o`, entity or biome flags in the baseline. These meanings and filename-first format arguments are verified in [ClipboardCommands](https://github.com/EngineHub/WorldEdit/blob/7d32b456e7c3237a70e19cca129e51b790c33b73/worldedit-core/src/main/java/com/sk89q/worldedit/command/ClipboardCommands.java#L145) and [SchematicCommands](https://github.com/EngineHub/WorldEdit/blob/7d32b456e7c3237a70e19cca129e51b790c33b73/worldedit-core/src/main/java/com/sk89q/worldedit/command/SchematicCommands.java#L105).
3. Compare complete native cell states after paste and after recorded ticks, save the world, quit/reopen, and compare again. Reselect the exact bounds, copy from the recorded origin, and save `//schem save roundtrip sponge.3`. Decode and compare semantic contents, including air and offsets; gzip bytes, palette ordering and timestamps need not match. Preserve logs and both files. A successful load alone fails this gate.
4. When extending the profile, add full block-entity/entity payload and biome comparisons, not only IDs/counts. Any state, origin, payload, reload or post-tick mismatch keeps the affected capability unqualified. Changed importer/game/registry/validator revisions require a new receipt.
