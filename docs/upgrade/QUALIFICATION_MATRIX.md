## Required journey fixtures

- **J01 First build:** open without account, choose control preset, place/erase using pointer and form, pan/frame, undo, save, reopen.
- **J02 Recovery:** edit while a save is pending, inject quota/abort, retain unsaved work, export it, recover a named copy, resolve two writers without silent loss.
- **J03 Game lock:** start from a compatible project, checkpoint and enable exact profile, attempt an unsupported mutation through every admitted route, prove document/history unchanged on rejection.
- **J04 Schematic:** asymmetric axis markers, negative/nonzero anchor, explicit air, unknown state, oversize bounds, corruption; native paste AND persisted save/reload AND export-back against the pinned candidate.
- **J05 Accessible precision:** perform a build using keyboard/forms, zoom 200%, identify selection without color alone, navigate all panels with screen reader, recover misplaced windows.
- **J06 Repair:** preview exact affected cells, reject stale Apply after intervening edit/profile switch, cancel before commit, undo a committed repair.
- **J07 Recipe/resource:** load admitted resource with provenance, run bounded recipe preview, apply one atomic operation, undo; reject malformed/oversized or missing dependencies.
- **J08 Scale/export:** repeat import/edit/export/project-switch on named devices; compare faithful geometry in an independent consumer, inspect resource growth and degraded-mode controls.

Each receipt names the exact fixture, environment, source/bundle identity and failed/unrun conditions. Native, provider, assistive-technology and performance lanes remain independent of source/build success. A failed fixture is a release boundary for that capability, not permission to erase user data or lower the assertion silently.
